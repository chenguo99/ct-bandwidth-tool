计算方法

公式模式：
每帧数据 = Header + Pixel × Slice × DBB × Datatype / 8 (Byte)
每圈数据 = View × 每帧数据 (Byte)

两种模式通用：
滑环有效速率 = 输入速率 × 0.8（8b/10b 编码损耗）
产生速率 = 每圈数据 / TimeRotation (Byte/s)
净积累速率 = 产生速率 − 滑环传输速率 (Byte/s) — 放线时滑环同时实时传输
放线时间 = 缓存空间 / 净积累速率 (s) — 仅当净积累 > 0
休息时间 = 缓存空间 / 滑环传输速率 (s) — 停止放线，滑环排空缓存
占空比 = 放线时间 / (放线时间 + 休息时间) × 100%

状态判定： 占空比 < 10% → 极限压力（红）｜10%–50% → 高压力（橙）｜50%–100% → 正常（绿）｜净积累 ≤ 0 → 可连续运行
